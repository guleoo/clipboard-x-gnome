## Fixes

- **Small-text synchronization**: fixed small clipboard entries incorrectly reporting that they
  exceeded the synchronization size limit when downloaded using HTTP chunked transfer or without
  a `Content-Length` header. Batch reception no longer generates repeated notifications from this error.
- **Download verification**: compressed responses such as gzip are checked against their decoded
  size, not the compressed HTTP length. Actual size limits, exact manifest size and SHA-256 checks
  remain enforced; a declared size mismatch now reports an integrity verification failure rather
  than a size-limit error. The strict requirements for optional `sha256sum` verification are unchanged.
