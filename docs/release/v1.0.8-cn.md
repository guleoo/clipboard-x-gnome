## 改进

- **敏感内容默认不记录**：应用标记为敏感的剪切板内容，默认不再进入历史记录。
  用户此前主动选择的策略保持不变。
- **隐私设置名称统一**：设置中的“暂停剪切板记录”改为“隐私模式”。

## 修复

- **完善取色器清理**：禁用插件时，在关闭取色器前显式断开其销毁信号；正常完成取色
  或取消时，也会清空信号 ID。
