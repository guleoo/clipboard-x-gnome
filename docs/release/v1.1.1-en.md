## Improvements

- **Text submission** is now the default simulated-input mode. It sends text in small blocks through
  GNOME's text-input connection without replacing the clipboard. For unsupported targets, manually
  select **Simulated keystrokes (compatibility)**, with Standard, Medium and Slow speed profiles.
  Overlapping input requests are rejected, and observed target changes cancel the remaining input.
  Keystrokes may still drop or reorder Unicode characters depending on the application and input method;
  prefer normal paste for long or exact content.
- **Word Selection opens before results load**, so you can go back or close it while waiting. Late
  results cannot reopen an outdated panel. Input over 20,000 Unicode code points is rejected without truncation.
- **More panel controls**: customize the text and icon foreground color, or follow the system theme.
  Escape in a secondary panel returns to history by default, with an option to close the panel instead;
  an open quick-phrase form closes first. The form also has a clickable confirmation button.

## Fixes

- Avoid a GJS crash when the logger handles native GLib/Gio errors, including errors during cancellation.
- Prevent image-editor commands such as `gradia %i` from blocking Shell while passing image data to standard input.
- Treat explicitly cancelled interactive screenshots as cancellation rather than reporting a capture failure.
- Exclude the color picker's own overlay and preview from its initial screen capture.
- Coordinate mouse and keyboard focus, hover feedback and tooltips. Restore right-arrow navigation out of
  the search field at its boundary, Enter to add a quick phrase, and consistent input-field padding.
- Avoid unnecessary history-row rebuilds when toggling synchronization or restoring completed-transfer state.
- Clean up simulated-input timers and panel callbacks on disable, and cancel pending requests and release
  preferences resources when the settings window closes.
