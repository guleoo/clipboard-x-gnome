## Changes

- **Extension name**: the extension is now named **Clipboard X Gnome**. The settings window,
  notifications, logs, documentation and release titles use the same name. Technical identifiers
  now consistently use `clipboard-x-gnome`, including the extension UUID, settings schema,
  translation domain and local data directory.
- **New extension identity**: GNOME treats this as a separate extension. Disable the old extension
  before installing this build. Settings and local data start fresh; existing data in the old
  directory is not deleted or automatically migrated.
- **About page**: settings now include an About page with the project website, issue tracker,
  `GPL-3.0-or-later` license and the installed version read from extension metadata.
- **About layout**: the version is bold and right-aligned. Project, issue tracker and license
  links open by activating their entire row, without separate Open buttons or a repeated extension name.
- **Translations**: About page labels are available in all 25 supported translation languages,
  in addition to English.
