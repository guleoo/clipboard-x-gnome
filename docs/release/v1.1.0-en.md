## Word selection and dictionaries

- **Configurable word limit**: added “Maximum words” under Preferences → Clipboard → Word Selection,
  with a default of 2,000 selectable items. Results exceeding the limit show a notification instead of
  opening a partially truncated panel.
- **Faster processing**: URLs, email addresses, and numbers are processed incrementally. Dense numeric
  text no longer triggers quadratic overlap checks, and processing stops as soon as the word limit is exceeded.
- **Dictionary edits take effect automatically**: saving a dictionary in an external editor reloads its
  words without restarting the extension. Editing its language header does not change its imported language.
- **Explicit dictionary languages**: imported files, including network dictionaries, must declare a valid
  `# locale: language-code` header. The language dropdown filters the dictionary list; it no longer assigns
  a language to files without a declaration. A failed network replacement preserves the existing dictionary.

## Synchronization

- **More reliable recovery**: preserve pending source-upload work across restarts and interrupted requests,
  retry incomplete responses, and show completed transfers correctly after recovery.
- **Respect newer clipboard choices**: an older, slower remote download no longer overwrites newer incoming
  content, a subsequent local copy, or an explicitly selected history entry.
- **Keep synchronization moving**: missing local originals no longer block later source uploads or download
  status updates. Received history is saved before acknowledging changes, and stale updates no longer
  displace active transfers in the panel.
- **Preserve content identity**: retries reuse the original publication, and pinning a remote entry no longer
  republishes it as local content. The outgoing rich-text setting is also clearer and is now grouped with
  the clipboard settings.

## Clipboard and everyday tools

- Preserve plain-text and HTML representations with identical payloads when history is saved and reopened,
  and protect shared originals and previews while they are still in use.
- Reopen large, valid quick-phrase collections without losing entries because of the previous file-size limit.
- Preserve panel focus and scroll position during refreshes, and respect newer mouse or keyboard input
  instead of restoring an outdated focus target. Contextual keypad shortcuts now match their recorded keys.
- Open cached images in standard-input editors without reading the entire image into memory again.
- Confirm the color at the latest selected position, including when sampling is still in progress.

## Compatibility

- GNOME Shell 51 is again included in the extension's supported-version metadata.
