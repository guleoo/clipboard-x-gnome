## 功能改进

- **模拟输入默认采用文本提交**：通过 GNOME 的文本输入通道分块发送，不替换剪切板内容。
  不支持的目标可手动选择“模拟按键（兼容）”，提供标准、中速、慢速三档。
  已有输入任务时拒绝重复请求，观察到目标改变时停止剩余输入。模拟按键仍可能漏字或错序，
  受目标应用和输入法影响，长文本或要求准确的内容建议使用普通粘贴。
- **分词面板先打开、再加载结果**：等待时可以返回或关闭，迟到的结果不会重新打开过时面板。
  超过 20,000 个 Unicode 码点的输入直接拒绝，不截断。
- **新增面板控制选项**：文字与图标颜色可自定义或跟随系统；非主面板按 Esc 默认返回历史，
  也可配置为直接关闭。快捷语句正在添加时先收起表单，表单同时新增可点击的确认按钮。

## 问题修复

- 避免日志处理原生 GLib/Gio 异常时触发 GJS 崩溃，包括取消操作期间的异常。
- 修复 `gradia %i` 等图片编辑命令通过标准输入传递图片时可能卡住 Shell 的问题。
- 主动取消交互截图时，不再误报截图失败。
- 取色器初始截图不再混入自身的遮罩和预览。
- 协调鼠标与键盘的焦点、悬停反馈和提示；修复搜索框右边界的方向键导航、快捷语句
  Enter 确认，以及输入框内边距不一致的问题。
- 切换同步或恢复已完成的传输状态时，避免不必要的历史条目重建。
- 禁用插件时清理模拟输入定时器与面板回调；设置窗口关闭时取消未完成请求并释放相关资源。
