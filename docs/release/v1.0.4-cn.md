## 修复

- **小文本同步**：修复下载使用 HTTP chunked 分块传输或未提供 `Content-Length` 时，
  小文本被误判为超过同步大小限制的问题，消除批量接收因此连续弹出错误通知的现象。
- **下载校验**：gzip 等压缩响应按照解压后的正文大小校验，不再与压缩后的 HTTP 长度
  混淆。实际大小上限、清单中的精确大小与 SHA-256 校验仍然生效；声明长度不匹配时
  提示完整性校验失败，而非超过大小限制。可选 `sha256sum` 校验模式的严格要求保持不变。
