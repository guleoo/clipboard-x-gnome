## Improvements

- **Synchronization-state persistence**: unchanged synchronization cursors no longer trigger
  repeated writes to `sync-state.json` on every poll, reducing disk activity and the creation and
  removal of temporary files. Changed state is still saved immediately and atomically, and failed
  writes remain retryable. The polling interval and synchronization behavior are unchanged.
