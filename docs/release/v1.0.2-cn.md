插件名称统一为 **Clipboard X Gnome**，扩展 UUID、设置与本地数据存储位置保持不变。

设置新增 **关于** 页面，展示版本号、项目地址、问题反馈地址与许可证。

## 问题修复

- **词库异步加载**：词库文件操作改为异步执行，解析与索引构建分批让出主循环，减少
  加载大词库时对桌面响应的阻塞。
- **分词缓存**：相同词库配置的并发请求共用一次加载；迟到结果不会覆盖新缓存。
  禁用扩展时取消未完成的加载，不返回只构建了一部分的词库。
- **面板切换**：用户切换到其他面板，或关闭菜单后重新打开时，迟到的分词结果不会
  再把界面切回分词面板。
- **词库设置**：迟到的列表结果不会覆盖当前所选语言的词库列表，也不会更新已关闭
  的设置窗口。导入、刷新和删除成功后，即使窗口已关闭，仍会通知分词器刷新缓存。
- **扩展生命周期**：按需同步的预览图标改为在扩展启用后的 UI 生命周期中创建，
  UI 销毁时释放，不再在导入模块时创建。

## 发布包调整

- 移除未使用的 JavaScript 模块，将暂未启用的设备图标颜色模块排除在安装与发布文件之外。
- 发布 ZIP 只包含设置 schema XML，不再附带冗余的编译产物；本地 Meson 安装仍会生成并
  安装编译后的 schema。
