## Improvements

- **Sensitive content is not recorded by default**: clipboard content marked as sensitive by
  applications is now discarded by default. Existing user-selected policies remain unchanged.
- **Clearer privacy setting**: renamed “Pause clipboard recording” to “Privacy mode” in settings.

## Fixes

- **Explicit color picker cleanup**: disconnect the color picker's destroy signal before closing
  it when the extension is disabled, and clear the signal ID after normal completion or cancellation.
