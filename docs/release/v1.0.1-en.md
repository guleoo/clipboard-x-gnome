## Fixes

- **History initialization**: synchronization now waits for local history to finish loading.
  Items added during startup are preserved, and an incomplete history can no longer overwrite
  the existing index or delete its saved content.
- **Synchronization restarts**: cancelled or late upload tasks can no longer restore old transfer
  states, send follow-up requests through a replacement connection, or clear a newer upload's
  operation record. Uploads requested during startup wait until initialization completes.
- **History on disable**: entries waiting for their automatic save are flushed asynchronously
  when the extension is disabled. Re-enabling waits for that save before loading history, preserving
  the most recently copied entries during rapid disable/re-enable cycles.

## Testing

- Fixed clipboard-source and UI test fixtures, including Wayland focus, GTK calls, button signals,
  and image layout checks; removed brittle assertions and redundant coverage.
- Added regression coverage for delayed initialization, interrupted uploads, and rapid lifecycle
  changes. Stabilized subprocess-readiness checks in development-session and file-verification tests.
