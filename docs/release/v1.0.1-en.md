## Fixes

- **Synchronization icons**: completed lazy publications now use a document-and-check icon,
  distinguishing synchronized previews from completed original-content transfers.
- **History initialization**: synchronization now waits for local history to finish loading.
  Items added during startup are preserved, and an incomplete history can no longer overwrite
  the existing index or delete its saved content.
- **Synchronization restarts**: cancelled or late upload tasks can no longer restore old transfer
  states, send follow-up requests through a replacement connection, or clear a newer upload's
  operation record. Uploads requested during startup wait until initialization completes.
- **Upload recovery**: pending publications now survive interrupted sessions in per-server queues,
  saved under `$XDG_DATA_HOME/clipboard-x/sync-queues/` and bound to their original Channel and
  DeviceId. Switching servers preserves the old queue without sending its tasks to the new server.
  Retries check local availability and reuse the server's publication before uploading bytes;
  already-completed publications do not upload their content again. Disabling synchronization pauses
  existing tasks, does not queue new entries, and does not backfill them when re-enabled.
- **Upload eligibility**: queued publications recheck their source before starting and before sending
  each object, preventing deleted or sensitive entries from beginning a later upload. Failed history
  loading no longer causes pending references to be treated as deleted. Explicit cancellation removes
  the pending task for the current destination; lifecycle cancellation retains it for recovery.
- **History on disable**: entries waiting for their automatic save are flushed asynchronously
  when the extension is disabled. Re-enabling waits for that save before loading history, preserving
  the most recently copied entries during rapid disable/re-enable cycles.

## Testing

- Fixed clipboard-source and UI test fixtures, including Wayland focus, GTK calls, button signals,
  and image layout checks; removed brittle assertions and redundant coverage.
- Added regression coverage for delayed initialization, interrupted uploads, rapid lifecycle
  changes, durable queue recovery, destination isolation, and synchronization being disabled.
- Stabilized GNOME 50/51 CI lifecycle checks with a self-contained background, disabled animations,
  explicit waits for actual extension enable/disable transitions, and stage-specific timeout diagnostics.
- Fixed test races by waiting for complete subprocess PID markers, retrying transient runtime-directory
  cleanup failures without overwriting the test's exit status, and serializing shared-file access in
  the HTTP fixture so cancelled uploads cannot overwrite subsequent test data.

## Notes

- Existing history entries that were never queued are not automatically backfilled; send previously
  missed entries manually.
- If connection initialization fails while offline, pending tasks are preserved, but automatic
  reconnect is not yet implemented. Re-enable synchronization or start a new session after connectivity
  returns.
