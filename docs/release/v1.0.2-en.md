The extension is now named **Clipboard X Gnome**. Its UUID, settings and local data locations are unchanged.

Settings now include an **About** page with the version, project website, issue tracker and license.

## Fixes

- **Asynchronous dictionaries**: dictionary file operations now run asynchronously. Parsing and
  lexicon construction yield between batches, reducing main-loop blocking when loading large dictionaries.
- **Tokenizer caching**: concurrent requests for the same dictionary configuration share one load.
  Late results cannot overwrite a newer cache, and disabling the extension cancels pending loading
  instead of returning a partially built dictionary.
- **Panel navigation**: delayed tokenizer results no longer switch panels after the user has navigated
  elsewhere or closed and reopened the menu.
- **Dictionary settings**: late list results cannot replace the currently selected language's rows
  or update a closed settings window. Successful imports, refreshes and removals still invalidate
  the tokenizer cache if the window closes before the operation finishes.
- **Extension lifecycle**: the lazy-sync preview icon is created within the enabled extension's
  lifecycle and released when its UI is destroyed, rather than created during module import.

## Packaging

- Removed an unused JavaScript module and excluded the temporarily disabled device-icon color
  modules from installed and published files.
- Release ZIPs now include the settings schema XML without the redundant compiled schema.
  Local Meson installations still generate and install the compiled schema.
