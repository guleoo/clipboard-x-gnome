## 改动

- **插件名称**：统一为 **Clipboard X Gnome**，设置窗口、通知、日志、文档与发布标题
  使用相同名称。项目标识仍为 `clipboard-x-gnome`，扩展 UUID、设置 schema 与本地数据
  存储位置保持不变。
- **关于页面**：设置新增关于页面，展示项目地址、问题反馈地址、`GPL-3.0-or-later`
  许可证，以及从扩展 metadata 读取的已安装版本号。
- **关于页布局**：版本号加粗并靠右显示；项目、问题反馈与许可证链接可点击整行打开，
  不再显示独立的“打开”按钮或重复的插件名。
- **多语言**：关于页面标签除英文外，已适配全部 25 种支持的翻译语言。

**Full Changelog**: [v1.0.2...v1.0.3](https://github.com/guleoo/clipboard-x-gnome/compare/v1.0.2...v1.0.3)
