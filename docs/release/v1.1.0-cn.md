## 分词与词库

- **可配置的分词上限**：在“设置 → 剪切板 → 分词”中新增“最大分词数量”，默认最多
  2,000 个可选项。超出上限时会提示，不会打开被静默截断的分词面板。
- **更快的分词处理**：链接、邮箱和数字改为按需处理。密集数字文本不再触发平方级的
  重叠检查，分词数量超限后立即停止处理。
- **词库编辑自动生效**：通过外部编辑器保存词库后，无需重启插件即可加载修改后的词语。
  编辑语言声明不会改变词库在导入时确定的所属语言。
- **明确词库语言**：导入的文件必须包含有效的 `# locale: 语言代码` 声明，网络词库也遵循
  此要求。语言下拉框只用于筛选词库列表，不再为缺少声明的文件指定语言。网络词库替换
  失败时会保留原有词库。

## 同步

- **改进中断恢复**：原文上传任务可在重启或请求中断后继续处理，不完整的响应可以重试，
  恢复成功后也会正确显示传输完成状态。
- **尊重更新的剪切板选择**：下载较慢的旧远端条目，不再覆盖较新的远端内容、用户随后
  复制的本机内容，或主动选择的历史条目。
- **避免单条任务阻塞同步**：本机原文文件丢失时，不再阻塞后续上传和下载状态刷新。
  收到的历史记录先保存再确认同步进度，过时的状态更新也不会挤掉面板中的活动传输。
- **保持内容身份一致**：重试沿用原有发布内容，固定远端条目不会将其作为本机内容重新
  上传。富文本发送配置的含义也更明确，并已归入剪切板设置。

## 剪切板与日常工具

- 修复正文相同的纯文本和 HTML 在历史保存、重新加载时丢失格式的问题；仍在使用的
  原文和预览不会因共享文件清理而提前删除。
- 修复合法的大型快捷语句集合因原有文件读取上限而无法完整加载的问题。
- 面板刷新时保留焦点与滚动位置，并尊重用户后续的鼠标和键盘操作，不再恢复到过时的
  焦点位置。面板内的小键盘快捷键也能与录制结果正确匹配。
- 将已缓存的图片传给支持标准输入的编辑器时，不再重新把整张图片读入内存。
- 取色时按最新选择的位置确认颜色，避免采样尚未完成时确认了旧位置的颜色。

## 兼容性

- 扩展元数据重新声明支持 GNOME Shell 51。
