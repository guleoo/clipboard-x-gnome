## 修复

- **过滤无效 HTML 剪切板片段**：仅含注释、文档元信息或空白的 HTML，不再生成显示为
  “文本”的空历史条目，也不会进入自动上传队列。正常富文本、HTML 图片和 SVG，以及同次
  复制的其他格式均保留。以纯文本形式复制的 HTML 源码不受影响。

## 调整

- 扩展元数据仅声明支持 GNOME Shell 50。
