## Improvements

- **Clearer English labels**: the word selection panel, its entry button and settings groups now
  consistently use **Word Selection** instead of **Segment text** or **Tokenizer**. Related shortcut
  labels refer to selected words, and the built-in segmenter is labeled **System word segmenter**.
  Translation catalogs have been updated while preserving existing translations.
- **Updated extension description**: refreshed the plugin description to cover its current features
  and clarify that optional clipboard synchronization requires a self-hosted clipboard server.
