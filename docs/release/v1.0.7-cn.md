## 修复

- **松开鼠标即结束连选**：修复分词模式单击后仍处于连选状态的问题。现在必须按住鼠标
  左键才能连续选择，松开即结束，在面板外松开也会结束。单击只切换当前词的选中状态。
- **回拖时缩小选择范围**：拖动作用于起点到当前词之间的区间，根据起点原来的选中状态
  执行选择或取消选择。向回拖动时，区间外的词恢复原来的状态，跨行拖动同样适用。

键盘选择行为保持不变。
