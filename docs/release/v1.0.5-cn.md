## 优化

- **同步状态保存**：同步游标未变化时，不再随每次轮询重复写入 `sync-state.json`，
  减少磁盘写入及临时文件的创建与删除。状态变化时仍立即原子保存，写入失败后仍可
  重试。轮询间隔与同步行为保持不变。
