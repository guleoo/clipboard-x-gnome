## 问题修复

- **同步图标**：按需传输条目发布成功后显示“预览文档 + 小勾”，区分已同步的预览
  与完整内容传输完成的状态。
- **历史初始化**：同步现在会等待本地历史加载完成后再启动。加载期间新增的条目会保留，
  不完整的历史不会再覆盖原有索引或删除已保存的内容。
- **同步重启**：取消或延迟完成的旧上传任务不会再写回旧传输状态、通过新连接继续发送
  请求，或误删新上传任务的操作记录。启动期间请求的上传会等待初始化完成。
- **上传恢复**：待发布任务按服务器持久化到 `$XDG_DATA_HOME/clipboard-x/sync-queues/`，
  并绑定提交时的 Channel 和 DeviceId。切换服务器保留原队列，不把旧任务发送到新服务器。
  重试时先检查本地内容并复用服务端发布记录，已完成的发布不重复传输正文。关闭同步暂停
  已有任务，不为新条目入队，重新开启也不自动补传关闭期间的条目。
- **上传资格检查**：排队的发布在真正开始和发送每个对象前重新检查来源，防止已删除或
  隐私条目在等待后开始上传。历史加载失败时，不再把待上传引用误判为已删除。手动取消
  移除当前目的地的任务；扩展启停或连接切换引起的取消保留任务，以便恢复。
- **禁用时保存历史**：扩展禁用时，会异步保存尚未自动落盘的条目；重新启用会等待保存
  完成后再读取历史，避免快速禁用、启用时丢失刚复制的内容。

## 测试改进

- 修正剪切板来源与 UI 测试中的 Wayland 焦点、GTK 调用、按钮信号及图片布局验证，
  移除脆弱断言与重复覆盖。
- 补充延迟初始化、上传中断、快速启停、持久化队列恢复、目的地隔离及关闭同步的回归测试。
- 完善 GNOME 50/51 CI 生命周期检查：使用自带背景、关闭动画，等待扩展实际完成启用或
  禁用，并提供分阶段的超时诊断。
- 修复测试竞态：等待子进程完整写入 PID 标记；重试运行时目录的临时清理失败，保留测试
  原始退出码；串行访问 HTTP 测试服务的共享文件，避免取消的上传覆盖后续测试数据。

## 说明

- 从未入队的历史条目不会自动补传；此前漏传的条目需手动发送一次。
- 启动时离线导致连接初始化失败，待上传任务会保留，但尚未实现自动重连。网络恢复后，
  请重新开启同步或重新登录。
