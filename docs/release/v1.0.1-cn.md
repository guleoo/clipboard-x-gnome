## 问题修复

- **同步图标**：按需传输条目发布成功后显示“预览文档 + 小勾”，区分已同步的预览
  与完整内容传输完成的状态。
- **历史初始化**：同步现在会等待本地历史加载完成后再启动。加载期间新增的条目会保留，
  不完整的历史不会再覆盖原有索引或删除已保存的内容。
- **同步重启**：取消或延迟完成的旧上传任务不会再写回旧传输状态、通过新连接继续发送
  请求，或误删新上传任务的操作记录。启动期间请求的上传会等待初始化完成。
- **禁用时保存历史**：扩展禁用时，会异步保存尚未自动落盘的条目；重新启用会等待保存
  完成后再读取历史，避免快速禁用、启用时丢失刚复制的内容。

## 测试改进

- 修正剪切板来源与 UI 测试中的 Wayland 焦点、GTK 调用、按钮信号及图片布局验证，
  移除脆弱断言与重复覆盖。
- 补充延迟初始化、上传中断和快速启停的回归测试。
- 完善 GNOME 50/51 CI 生命周期检查：使用自带背景、关闭动画，等待扩展实际完成启用或
  禁用，并提供分阶段的超时诊断。
- 修复测试竞态：等待子进程完整写入 PID 标记；重试运行时目录的临时清理失败，保留测试
  原始退出码；串行访问 HTTP 测试服务的共享文件，避免取消的上传覆盖后续测试数据。
