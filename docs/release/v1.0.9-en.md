## Fixes

- **Ignore empty HTML clipboard fragments**: HTML containing only comments, document metadata,
  or whitespace no longer creates empty history entries labeled “Text” or enters the automatic
  upload queue. Normal rich text, HTML images and SVG, and other formats from the same copy are preserved.
  Plain text containing HTML source is unaffected.

## Changes

- Extension metadata now declares support for GNOME Shell 50 only.
